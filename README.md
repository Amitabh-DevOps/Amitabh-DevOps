## 🌟 About Me

I'm Amitabh Soni, a Cloud & DevOps Engineer and AWS Community Builder in the Containers category.

I focus on building automated, scalable, and reliable infrastructure using AWS and modern cloud-native technologies. My hands-on work includes Infrastructure as Code, containerization, CI/CD automation, Kubernetes, cloud deployments, observability, and DevSecOps practices.

Beyond engineering, I'm also a technical content creator, where I share hands-on tutorials, real-world projects, and practical learning resources around AWS, Docker, Kubernetes, and DevOps.

🚀 **Current Focus**:

- ☁️ Building cloud-native infrastructure and automation on AWS
- 🐳 Working with Docker, Kubernetes, and containerized applications
- ⚡ Automating infrastructure with Terraform and Ansible
- 🔄 Building CI/CD and GitOps workflows
- 📈 Implementing monitoring and observability with Prometheus and Grafana
- 🔐 Exploring DevSecOps and security automation practices
